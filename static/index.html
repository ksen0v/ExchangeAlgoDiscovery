      Какие биржи мониторить

      Выбор сохраняется отдельно для каждой монеты. Отключённые биржи не подключаются ни к ленте, ни к плитам, ни к открытому интересу.

      Плиты

      Только для этой биржи и этой монеты. Например, у маркетмейкера на бирже постоянно стоят плотности по $1M — их можно не считать плитами.
