# Manipulation Radar 1.0.3

- **Мгновенный отклик при добавлении монеты.** Инструмент сразу появляется в списке, а подключение бирж выполняется в фоне. Под тикером видно подготовку, количество подключённых площадок и возможные ошибки; при ошибке сохранения можно повторить добавление.
- **Более плавное подключение бирж.** Подготовка новых подключений выполняется в фоне, а интерфейс остаётся доступным для работы с другими монетами.
- **Настройки фона оверлея.** Через «⋯ → Настройки оверлея» выбирайте непрозрачный или прозрачный фон и регулируйте его плотность. Текст и линии графиков остаются чёткими. Настройки сохраняются отдельно для каждого окна.
- **Доступное управление при сквозных кликах.** Нажатия по содержимому проходят в терминал, а заголовок с меню, кнопкой разблокировки и закрытия остаётся нажимаемым. Отключить режим можно непосредственно в оверлее.
- **Согласованные режимы.** Включение сквозных кликов автоматически делает фон прозрачным. Выбор непрозрачного фона возвращает обычное управление окном.

Для первой установки скачайте **ManipulationRadar-Setup.exe**. Для обновления откройте **☰ → Проверить обновления** в приложении.
