# Manipulation Radar 1.0.2

Удобный монитор рыночных данных в помощь скальперу — рядом с вашим торговым терминалом.

В этом выпуске:

- **Список инструментов слева.** Добавляйте любое количество монет и переключайте рабочий стол нажатием на тикер. Для каждой монеты доступны все модули, свой выбор бирж и отдельная история CVD и OI.
- **Переключение без переподключения.** Уже добавленные монеты продолжают наблюдаться, а накопленная аналитика сохраняется при переходе между ними.
- **Любой модуль в оверлее.** Нажмите ⋯ или правую кнопку мыши по модулю и выберите «Разместить оверлей». Окно сохраняет выбранную монету и настройки независимо от рабочего стола.
- **Сквозные клики для каждого оверлея.** Управляйте ими через меню модуля или окна. Отключить режим у всех окон можно через меню приложения или горячую клавишу.
- **Более спокойный интерфейс.** Дополнительная верхняя служебная панель убрана. Обновления, подключение, горячие клавиши, тема и звук собраны в меню ☰.

Для первой установки скачайте **ManipulationRadar-Setup.exe**. Для обновления откройте **☰ → Проверить обновления** в приложении. Ваши рабочие пространства и настройки сохраняются.
